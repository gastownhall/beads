`bd help --doc types`에서 생성되었습니다.

bd create --type에 사용할 수 있는 유효한 모든 이슈 유형을 나열합니다.

핵심 작업 유형(bug, task, feature, chore, epic, decision)은 항상 유효합니다.
추가 유형에는 .beads/config.yaml의 types.custom 구성이 필요합니다.

예시:
  bd types              # 모든 유형과 설명 나열
  bd types --json       # JSON으로 출력


```
bd types [flags]
```
