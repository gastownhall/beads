`bd help --doc branch`에서 생성되었습니다.

모든 브랜치를 나열하거나 새 브랜치를 생성합니다.

이 명령에는 Dolt 저장소 백엔드가 필요합니다. 인수가 없으면 모든 브랜치를
나열하고, 인수가 있으면 새 브랜치를 생성합니다.

예시:
  bd branch                    # 모든 브랜치 나열
  bd branch feature-xyz        # feature-xyz라는 새 브랜치 생성

```
bd branch [name] [flags]
```
