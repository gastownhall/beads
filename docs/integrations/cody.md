---

프로젝트 규칙 파일을 통해 Sourcegraph Cody에서 Beads를 사용합니다.

```bash
bd setup cody
bd setup cody --check
```

설정 명령은 Beads 워크플로 지침이 담긴 `.cody/rules/beads.md`를 생성합니다.

## 제거

```bash
bd setup cody --remove
```
