---
title: OpenCode
description: AGENTS.md의 관리형 Beads 섹션을 통해 OpenCode에 Beads 워크플로 컨텍스트 제공
---

관리형 `AGENTS.md` 지침을 통해 OpenCode에서 Beads를 사용합니다.

```bash
bd setup opencode
bd setup opencode --check
```

설정 명령은 관리형 Beads 섹션으로 `AGENTS.md`를 생성하거나 업데이트합니다. OpenCode가 이미 실행 중이면 설정 후 다시 시작하세요.

## 제거

```bash
bd setup opencode --remove
```
