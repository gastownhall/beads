---

프로젝트 규칙 파일을 통해 Windsurf에서 Beads를 사용합니다.

```bash
bd setup windsurf
bd setup windsurf --check
```

설정 명령은 Beads 워크플로 지침이 담긴 `.windsurf/rules/beads.md`를 생성합니다.

## 제거

```bash
bd setup windsurf --remove
```
