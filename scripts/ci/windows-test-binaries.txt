# Manifest for the Windows cross-compile job (scripts/ci/build-windows-test-binaries.sh).
#
# Each non-comment, non-blank line is: name cgo tags package
#   name    - output file name. A name ending in ".test.exe" is built with
#             `go test -c` (a standalone test binary); anything else is built
#             with `go build` (a regular executable, e.g. bd.exe).
#   cgo     - 0 or 1. Matches what the native Windows job this binary replaces
#             used: explicit CGO_ENABLED=0 where the job set it, 1 where it
#             relied on the windows-latest runner default (which is 1 - gcc is
#             on PATH there). cgo=1 entries cross-compile with
#             CC=x86_64-w64-mingw32-gcc CXX=x86_64-w64-mingw32-g++, the same
#             mingw toolchain release.yml's goreleaser job uses for the
#             shipped bd-windows-amd64 binary (see .goreleaser.yml).
#   tags    - Go build tags, comma-separated, no spaces (e.g. gms_pure_go or
#             integration,gms_pure_go).
#   package - the Go package import path/pattern to build or test-compile.
#
# This is the advisory-phase manifest: it covers only the two cmd/bd-backed
# Windows jobs that currently have "-prebuilt" twins
# (test-windows-liveness-prebuilt, worktree-remove-windows-prebuilt) in
# pr.yml. The windows legs of pr-preflight-platforms and
# check-doc-freshness-platforms, and the small CGO=0 packages, are unscheduled
# follow-up work and are NOT yet listed here or consumed by any job.
#
# name                     cgo  tags          package
