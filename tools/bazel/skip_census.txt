# Runtime skip census (tools/bazel/check_skip_census.py; C7(a) of the bringup
# test plan): every Go test or subtest the Dolt-tier lanes skip.
# One skip per line, sorted: <label> <test path> <class>.
# Classes: KNOWN DIVERGENCE <row> | KNOWN BDP DIVERGENCE <row> |
#   WAITING ON <ref> | nil-hook <Hook> | env-gate <VAR> (test path *) | other.
# A new skip, or a line whose test runs again, fails the lane's
# "Every target and shard ran tests" step (check_testcases.py --skip-census).
# Lines naming a target a run did not test are not judged, so one file serves
# every lane. '#' starts a comment only at the start of a line (WAITING ON
# refs contain '#').
# To park a case: copy the line the failing step prints under "add to", keep
# the file sorted, and delete the line again when the case is unparked.
# Regenerate: python3 tools/bazel/check_skip_census.py --write --testlogs-dir DIR
#   (DIR: a lane's "Upload test logs" artifact from a run on rbe-west; the
#   dolt-int job uploads nothing when only the census fails, so for it copy the
#   printed "delete from"/"add to" lines). Modes cache and local only report.
# A skip that depends on process-global state left by earlier tests is not
# stable: rules_go shards tests round-robin by index, so any added or removed
# test in the package changes what ran first. Fix such a test, do not list it.
# Only these header comments survive --write.
# Check:      python3 tools/bazel/check_skip_census.py --lint
